Process

How I run a groupbuy

It starts with designing something I genuinely like. Once that's done I usually prototype it myself, though sometimes I'll let someone else build the proto instead. Either way it gets tested, and then the unit is theirs to keep.

If the board turns out popular and enough people want one, I'll do a small run and fulfill it myself. I aim for transparency throughout, and I don't take a large profit on my runs. This hobby is expensive enough already.

    Design

    Something I genuinely like

  2. 02

    Prototype

    Built by me, or by a tester

  3. 03
