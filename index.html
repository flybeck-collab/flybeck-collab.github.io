03_ABOUT

How I run a groupbuy

It starts with designing something I genuinely like. Once that's done I usually prototype it myself — sometimes I'll let someone else build the proto instead. Either way it gets tested, and then the unit is theirs to keep.

If the board turns out popular and enough people want one, I'll do a small run and fulfill it myself. I aim for transparency throughout, and I don't take a large profit on my runs — this hobby is expensive enough already.

PROCESS.LOG

  1. DESIGN — something I genuinely like
  2. PROTO — built by me, or by a tester
  3. TEST — then the proto unit is theirs
  4. DEMAND — it only runs if people want it
  5. RUN — small batch, minimal margin
  6. FULFILL — packed and shipped by me
